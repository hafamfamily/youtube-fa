# نقشهٔ بومی‌سازی youtube-fa

مبنا: [youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) (Jake Schincariol, MIT، نسخهٔ ۱.۰.۰).
الگو: همان کاری که در instagram-fa انجام شد؛ ترجمه نیست، بازنویسی برای زبان و شرایط فارسی است.

## اصل‌هایی که از نسخهٔ اصلی نگه می‌داریم
- هیچ چیز بدون «بله»ی کاربر منتشر نمی‌شود (مگر خودش حالت خودکار را روشن کند).
- هیچ عددی ساخته نمی‌شود؛ اگر نیست، پرسیده می‌شود یا جمله بدون آن نوشته می‌شود.
- امتیاز قلاب «هشدار» است، نه پیش‌بینی بازدید.
- ویدیوهای موفق با «چند برابرِ میانهٔ همان کانال» سنجیده می‌شوند، نه بازدید خام.
- هر اسکیل به‌تنهایی کار می‌کند؛ ابزارهای پایتونی بدون کتابخانهٔ جانبی.

## چیزهایی که برای فارسی عوض می‌شود

| اسکیل | از اصل | بازنویسی فارسی |
|---|---|---|
| `yt-setup` | — (فقط voice.md) | **تازه.** شناسنامهٔ کانال + `voice.md` فارسی + چند کانال؛ مثل ig-setup |
| `yt-script` | ۲۱ فرمول انگلیسی، hookscore انگلیسی | ۲۱ فرمول قلاب فارسی برای ۱۵ ثانیهٔ اول ویدیوی بلند؛ hookscore با موتور فارسی instagram-fa (نیم‌فاصله، رقم فارسی، عدد گفتاری) و سرعت گفتار فارسی |
| `yt-package` | title.py انگلیسی | طول دیداری بدون نیم‌فاصله، تکرار کلمه بین عنوان و تامبنیل با ریشهٔ فارسی، کلیشه‌های فارسی («باورتون نمیشه»، «فوری»)، ترکیب راست‌به‌چپ با اسم لاتین |
| `yt-edit` | تکیه‌کلام‌های انگلیسی (um, like) | تکیه‌کلام‌های فارسی: «اِم»، «اِ»، «یعنی»، «خب»، «ببین»، «چیزه»، «درواقع»، «به‌هرحال»؛ تشخیص تکرار جمله (برداشت دوباره) با نرمال‌سازی فارسی |
| `yt-chapters` | قواعد یوتیوب | همان قواعد؛ زمان‌ها با رقم لاتین، عنوان‌ها فارسی و کوتاه، چیدمان درست راست‌به‌چپ |
| `yt-retention` | CSV انگلیسی استودیو | ستون‌های فارسی استودیو هم خوانده می‌شود؛ گزارش فارسی |
| `yt-shorts` | انتخاب لحظه از زیرنویس | همان؛ جملهٔ اول تازه با فرمول‌های قلاب فارسی |
| `yt-seo` | توضیحات و تگ | جست‌وجوی فارسی + فینگلیش + انگلیسی؛ اینکه مخاطب داخل یا خارج ایران است در کلمه‌ها اثر دارد |
| `yt-comment` | چهار دسته | ادب و عرف ایرانی (مثل ig-engage)، جواب به شبهه و توهین بدون دعوا |
| `yt-plan` | برنامهٔ هفته | **اکسل رنگی راست‌به‌چپ با تاریخ شمسی** (موتور ig-plan) و هشدار وقتی برنامه از وقت واقعی بیشتر است |
| `yt-viral` | swipe.py انگلیسی | دسته‌بندی فرمول با فرمول‌های فارسی؛ دادهٔ دستی یا خوانده‌شده، بدون ورود به حساب |
| `yt-audit` | بررسی کانال | همان؛ نتیجه در `insights.md` که بقیه می‌خوانند |
| `yt-human` | — | **تازه.** انسانی‌ساز فارسی (همان ig-human) پیش از نشان دادن هر فیلم‌نامه و توضیحات |
| `yt-thumb` | — | **تازه.** ساخت تامبنیل فارسی |
| `yt-publish` | — | **تازه.** تأیید و انتشار یوتیوب و آپارات |

## افزوده‌ها (تصمیم صاحب پروژه)
- `yt-thumb`: تامبنیل فارسی ۱۲۸۰×۷۲۰ با موتور فارسی instagram-fa (Pillow + raqm، وزیرمتن و لاله‌زار). ✅
- `yt-publish`: حالت تأیید دستی/خودکار مثل instagram-fa؛ آپلود یوتیوب با YouTube Data API و OAuth خود کاربر. ✅
- آپارات: نسخهٔ هم‌زمان؛ آپلود خودکار تجربی با API عمومی قدیمی آپارات، یا پوشهٔ آماده برای آپلود دستی. ✅

## شرایط ایران که در همهٔ اسکیل‌ها لحاظ می‌شود
- مخاطب داخل ایران با فیلترشکن و اینترنت ناپایدار می‌بیند؛ ابتدای ویدیو باید کوتاه‌تر و بی‌مقدمه‌تر باشد.
- ساعت انتشار به وقت مخاطب؛ برای مخاطب خارج از کشور، وقت تهران معیار نیست.
- موسیقی و تصویر فقط با حق استفاده (Content ID).
