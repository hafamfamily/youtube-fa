# yt-edit — فهرست برش

از زیرنویس زمان‌دار، فهرست برش می‌سازد. برش‌ها را چاپ می‌کند؛ اعمالشان با تو و نرم‌افزار تدوینت.

اسکریپت‌ها کنار همین SKILL.md هستند. «<اسکیل‌ها>» پوشهٔ والد این اسکیل است. روی ویندوز `python`
(یا `py`)، روی مک و لینوکس `python3`. هیچ‌کدام کتابخانهٔ جانبی لازم ندارند مگر جایی که گفته شده.

```bash
python <اسکیل‌ها>/yt-edit/deadair.py transcript.srt                 # srt، vtt یا JSON خروجی Whisper
python <اسکیل‌ها>/yt-edit/deadair.py transcript.srt --floor 0.35
python <اسکیل‌ها>/yt-edit/deadair.py transcript.srt --csv cuts.csv   # فهرست برش برای جدول
```

**زیرنویس هنوز نداری؟** یکی از این‌ها، به ترتیب سادگی:
- آپلود «خصوصی» یا «فهرست‌نشده» در یوتیوب؛ بعد از چند دقیقه زیرنویس خودکار فارسی را از استودیو
  (Subtitles) دانلود کن.
- برنامهٔ رایگان Subtitle Edit (ویندوز) با موتور Whisper، یا whisper.cpp / faster-whisper.
زمان‌ها را حدس نزن.

## چه پیدا می‌کند

- **سکوت:** مکث‌های بلندتر از آستانه، که از **وسط** بریده می‌شوند تا دو طرف نفس بماند. برش چسبیده به
  گفتار، صدا را نفس‌بریده می‌کند.
- **پرکننده:** تکه‌هایی که چیزی جز «اِم»، «اِ»، «خب»، «یعنی»، «چیزه»، «ببین»، «درواقع»، «به‌هرحال» ندارند.
- **تکرار:** جمله‌ای که دوباره شروع شده؛ برداشت اول حذف می‌شود. با آخرین تکهٔ «گفتاری» مقایسه می‌شود،
  چون بین دو برداشت معمولاً یک «اِم» هست.
- **شمارش تکیه‌کلام** وسط جمله‌ها (که بریدنشان کار ابزار نیست): برای تمرین ضبط بعدی.

## چه نمی‌کند

به فایل ویدیو دست نمی‌زند. دربارهٔ تصویرهای مکمل نظری ندارد. درصد حذف یعنی درصد **گفتار**؛ اگر ویدیو
یک دموی بی‌صدای طولانی دارد، آن عدد غلط است. پیش از اعتماد به مدت نهایی، گزارش را با فیلم مقایسه کن.

## چه تحویل بدهی

جدول برش‌ها (یا فایل CSV)، مجموع حذف و مدت نهایی، و یک خط دربارهٔ پرتکرارترین تکیه‌کلام. اگر سکوت‌ها
زیاد بود، یک پیشنهاد عملی برای ضبط بعدی (مثلاً «نقطه‌گذاری فیلم‌نامه را با مکث تمرین کن»).

## دروازه

این اسکیل فقط **می‌نویسد**. هیچ چیزی بدون تصمیم صاحب کانال منتشر نمی‌شود؛ انتشار فقط از راه
`yt-publish` و طبق حالت کانال (دستی یا خودکار). هر خروجی به یک بلوک قابل‌کپی ختم می‌شود و آخرین خط
هر اجرا این سؤال است: **همین را نگه داریم، یا تغییرش بدهم؟**
