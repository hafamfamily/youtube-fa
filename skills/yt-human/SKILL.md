# yt-human — انسانی‌ساز فارسی

همان ابزار `ig-human` از instagram-fa، با کلیشه‌های گفتاری یوتیوب اضافه‌شده. هر متنی که بقیهٔ اسکیل‌ها
می‌نویسند، پیش از دیده شدن از اینجا رد می‌شود.

اسکریپت‌ها کنار همین SKILL.md هستند. «<اسکیل‌ها>» پوشهٔ والد این اسکیل است. روی ویندوز `python`
(یا `py`)، روی مک و لینوکس `python3`. هیچ‌کدام کتابخانهٔ جانبی لازم ندارند مگر جایی که گفته شده.

```bash
python <اسکیل‌ها>/yt-human/humanize.py draft.txt --out clean.txt     # اصلاح خودکار + گزارش
python <اسکیل‌ها>/yt-human/detect.py draft.txt clean.txt             # پنل پیش و پس
```

## چه چیزی خودکار درست می‌شود

1. **نامرئی‌ها:** فاصلهٔ صفرعرض، BOM، کاراکترهای کنترل جهت. **نیم‌فاصله هرگز حذف نمی‌شود**؛ بخشی از
   املای فارسی است.
2. **نشانه‌گذاری:** خط تیرهٔ بلند، گیومهٔ انگلیسی به «»، ی و ک عربی به فارسی.
3. **نیم‌فاصلهٔ جاافتاده:** «می خوام» ← «می‌خوام»، «ویدیو ها» ← «ویدیوها». اگر عمدی است: `--no-zwnj`.
4. **کلیشه‌ها** از `slop.json`: شروع‌های کلیشه، فعل‌های اداری، هیجان مصنوعی، پایان‌های کلیشه، و
   **کلیشه‌های یوتیوب** (سلام طولانی، خوش‌آمد به کانال، «قبل از شروع»، درخواست لایک و سابسکرایب در
   شروع، «بریم که داشته باشیم»).

## چه چیزی را باید خودت درست کنی

گزارش «دستی درست کن» ساختارهایی را نشان می‌دهد که regex درست بازنویسی نمی‌کند: «این فقط X نیست، بلکه
Y»، «نه تنها... بلکه»، «آیا تا به حال...؟»، سه صفت پشت هم. با جملهٔ خودت و لحن `voice.md` بازنویسی کن.

## پنل

تنوع جمله، مشخص‌بودن، کلیشه، اثر انگشت و صدا. زیر ۶۰ «پرچم خورده»، ۶۰ تا ۷۵ «مرزی»، بالای ۷۵ «انسانی».
آشکارساز رسمی نیست؛ نشانه‌هایی را می‌شمارد که شنونده حس می‌کند. برای قلاب، `hookscore.py` معتبرتر است.

اگر بعد از اصلاح هنوز زیر ۶۰ است، معمولاً یعنی متن عدد و مثال ندارد: از کاربر یک جزئیات واقعی بپرس،
نه اینکه کلمه‌ها را جابه‌جا کنی. `slop.json` مال صاحب کانال است؛ عبارت اضافه یا کم کن.
