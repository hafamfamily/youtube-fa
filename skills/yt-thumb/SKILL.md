# yt-thumb — تامبنیل

تامبنیل در اندازهٔ کوچک دیده می‌شود، نه در ۱۲۸۰ پیکسل. برای همین هر بار برگهٔ مقایسه بساز و نشان بده.

اسکریپت‌ها کنار همین SKILL.md هستند. «<اسکیل‌ها>» پوشهٔ والد این اسکیل است. روی ویندوز `python`
(یا `py`)، روی مک و لینوکس `python3`. هیچ‌کدام کتابخانهٔ جانبی لازم ندارند مگر جایی که گفته شده.

```bash
pip install pillow                          # یک بار
python <اسکیل‌ها>/yt-thumb/thumb.py --check   # آماده بودن فونت‌ریزی فارسی
python <اسکیل‌ها>/yt-thumb/thumb.py spec.json --out <پوشهٔ ویدیو>/thumb/thumb.png --preview
python <اسکیل‌ها>/yt-thumb/thumb.py a.json b.json c.json --out-dir <پوشهٔ ویدیو>/thumb --preview
```

اگر `--check` بگوید `raqm` نیست (بعضی نصب‌های ویندوز): `pip install arabic-reshaper python-bidi` و دوباره.
نمونهٔ هر چیدمان در `yt-thumb/examples/` است.

## پیش از ساختن

1. بریف را از `yt-package` بگیر: دو تا چهار کلمه، کدام کلمه برجسته (`*کلمه*`)، چیدمان، عکس.
2. `brand.json` کانال: رنگ‌ها، فونت نمایشی (`vazir` یا `lalezar` یا فونت خود کاربر در `fonts/`)، رقم فارسی
   یا لاتین، و عنصر امضا (`thumb.signature`: `bar`، `corner`، `frame`).
3. عکس: عکس واقعی کاربر (چهره با حالت روشن، شیء اصلی) خیلی بهتر از تصویر عمومی است. از او بخواه.
   اگر از تصویر ساخته‌شده با هوش مصنوعی استفاده شد و واقع‌نماست، در `meta.json` بنویس `"synthetic": true`.

## spec

```json
{"layout": "split", "kicker": "زیر ۲ میلیون", "text": "این میکروفون *۹۰۰ تومنی*",
 "photo": "face.jpg", "photo_side": "left", "focus": [0.5, 0.35]}
```

| چیدمان | کِی |
|---|---|
| `bold` | بدون عکس؛ یک ادعای کوتاه و قوی |
| `split` | چهره یا محصول یک طرف، متن طرف دیگر؛ پرکاربردترین |
| `photo` | عکس خودش داستان را می‌گوید؛ متن روی سایه |
| `versus` | مقایسهٔ دو گزینه (`a`، `b`) |
| `number` | یک عدد بزرگ (درصد، مبلغ، زمان) و برچسب کوتاه |

ابزار خودش: متن را تا جای ممکن درشت می‌کند، گوشهٔ پایین‌راست را برای نشان مدت ویدیو خالی می‌گذارد،
رنگ متن را با کنتراست بیشتر انتخاب می‌کند، و اگر متن در کمترین اندازهٔ خوانا هم جا نشد هشدار می‌دهد
(کد خروج ۳): یعنی متن را کوتاه کن، نه فونت را ریز.

## چه تحویل بدهی

دو یا سه نسخه با برگهٔ `preview.png` (اندازه‌های ۶۴۰، ۳۶۰ و ۱۶۸ پیکسل). بپرس کدام. نسخهٔ انتخاب‌شده را
`thumb/thumb.png` پوشهٔ ویدیو بگذار (یا مسیرش را در `meta.json` → `"thumb"`). همان تصویر برای آپارات هم
کار می‌کند.

## مرز

لوگو، شخصیت یا تصویر محافظت‌شدهٔ دیگران (برند، کارتون، عکس آدم مشهور) را در تامبنیل نگذار؛ هم
ممکن است گزارش حق نشر بخورد و هم بیننده را گمراه کند.
