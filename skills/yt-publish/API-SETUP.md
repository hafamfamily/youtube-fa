# راه‌اندازی آپلود خودکار

این کار یک بار انجام می‌شود. بدون آن هم همه‌چیز کار می‌کند: پوشهٔ `ready/` هر ویدیو را با ویدیو،
تامبنیل، عنوان، توضیحات، تگ و چک‌لیست برای آپلود دستی آماده می‌کند.

> نام دکمه‌ها و منوهای سایت‌های گوگل و آپارات گاهی عوض می‌شود. اگر چیزی با این راهنما نخواند، دنبال
> همان مفهوم بگرد یا به Claude بگو صفحه را ببیند.

## یوتیوب (حدود ۲۰ دقیقه)

**پیش‌نیاز:** حساب گوگلِ صاحب کانال، و دسترسی به سایت‌های گوگل (از ایران معمولاً با فیلترشکن). اگر
فیلترشکن به‌صورت پراکسی است، پیش از اجرای دستورها متغیر `HTTPS_PROXY` را بگذار، مثلاً روی ویندوز:
`set HTTPS_PROXY=http://127.0.0.1:10809`.

1. **پروژه:** به console.cloud.google.com برو و یک پروژهٔ تازه بساز (مثلاً `youtube-fa`).
2. **فعال کردن API:** APIs & Services ← Library ← «YouTube Data API v3» ← Enable.
3. **صفحهٔ رضایت OAuth:** APIs & Services ← OAuth consent screen (یا Google Auth Platform):
   - نوع کاربر: External.
   - نام اپ، ایمیل پشتیبانی و ایمیل توسعه‌دهنده را پر کن.
   - در بخش Test users، ایمیل گوگل صاحب کانال را اضافه کن.
   - **مهم:** وقتی وضعیت اپ «Testing» است، گوگل توکن را بعد از ۷ روز باطل می‌کند و هر هفته باید دوباره
     login کنی. برای استفادهٔ شخصی، وضعیت را روی «In production» بگذار (Publish app). لازم نیست اپ را برای
     بررسی گوگل بفرستی؛ فقط موقع ورود صفحهٔ هشدار «Google hasn't verified this app» می‌آید که با
     Advanced ← Go to … (unsafe) رد می‌شود، چون اپ مال خودت است.
4. **کلید:** APIs & Services ← Credentials ← Create credentials ← OAuth client ID ← نوع
   **Desktop app** ← Create ← Download JSON. این فایل را در پوشهٔ کانال نگه دار (نه در گیت).
5. **وصل کردن** (در ترمینال روی کامپیوتر خودت):
   ```bash
   python yt_api.py login --channel <پوشهٔ کانال> --client-secret <مسیر فایل JSON>
   ```
   مرورگر باز می‌شود؛ با حساب صاحب کانال وارد شو و اجازه بده. بعد «وصل شد: کانال …» می‌بینی.
6. **روش انتشار را خودکار کن:**
   ```bash
   python publish.py method --channel <پوشهٔ کانال> --youtube api
   ```

**بعد از اتصال بدان:**
- **تامبنیل سفارشی** و **ویدیوی بالای ۱۵ دقیقه** نیاز دارند کانال با شماره تلفن تأیید شده باشد
  (youtube.com/verify). اگر نباشد، ویدیو آپلود می‌شود ولی تامبنیل نه؛ گزارش می‌گوید.
- **سهمیهٔ API:** پروژهٔ تازه سهمیهٔ روزانهٔ محدودی دارد. برای یک کانال شخصی معمولاً کافی است؛ اگر پر شد،
  گزارش می‌گوید و روز بعد دوباره امتحان می‌شود.
- **وضعیت خصوصی:** گوگل در گذشته ویدیوهای پروژه‌های بررسی‌نشده را خصوصی نگه می‌داشت. این ابزار بعد از
  هر آپلود وضعیت واقعی ویدیو را می‌خواند و اگر با چیزی که خواسته شده فرق داشت، در گزارش می‌گوید.
- **زمان‌بندی:** با `youtube_schedule: true` (پیش‌فرض)، ویدیوی تأییدشده همان موقع آپلود می‌شود و خود
  یوتیوب سر ساعت منتشرش می‌کند؛ لازم نیست کامپیوتر سر ساعت روشن باشد.

قطع اتصال: `python yt_api.py logout --channel …` و برداشتن دسترسی در myaccount.google.com/permissions.

## آپارات (حدود ۵ دقیقه، تجربی)

آپارات API رسمی و مستندِ به‌روزی برای آپلود منتشر نکرده. این ابزار از API عمومی قدیمی آپارات استفاده
می‌کند که کتابخانه‌های متن‌باز هم با آن کار کرده‌اند، ولی ممکن است هر زمان عوض شود یا با ورود دومرحله‌ای
کار نکند. اگر کار نکرد، روش آپارات را دستی نگه دار.

1. ```bash
   python aparat_api.py login --channel <پوشهٔ کانال>
   ```
   نام کاربری و رمز آپارات را **در ترمینال** وارد کن، نه در گفتگو با Claude. رمز ذخیره نمی‌شود؛ فقط
   توکن ورود.
2. دستهٔ ویدیوها: `python aparat_api.py categories` و شمارهٔ دسته را در `publish.json` بگذار
   (`"category_aparat": 7`) یا برای هر ویدیو در `meta.json` (`"aparat": {"category": 7}`).
3. ```bash
   python publish.py method --channel <پوشهٔ کانال> --aparat api
   ```
4. یک بار با `python publish.py publish <ویدیو> --only aparat --dry-run` و بعد با یک ویدیوی آزمایشی
   امتحان کن.

## زمان‌بند روی کامپیوتر خودت

برای اینکه ویدیوهای رسیده سر وقت بروند (آپارات، یا یوتیوب بدون زمان‌بندی خود یوتیوب):

```bash
python publish.py schedule            # فقط نشان می‌دهد چه چیزی تنظیم می‌شود
python publish.py schedule --apply    # تنظیم (ویندوز: Task Scheduler؛ مک و لینوکس: crontab)
python publish.py schedule --remove --apply
```

کامپیوتر باید در ساعت انتشار روشن و به اینترنت (و در صورت نیاز فیلترشکن) وصل باشد. گزارش هر اجرا در
`<پوشهٔ کانال>/publish.log` است.

## امنیت

- فایل رمزها: `<خانهٔ کانال‌ها>/.secrets/<نام کانال>.json`؛ فقط برای کاربر خود سیستم خواندنی است.
  هرگز در گیت، گفتگو یا جای عمومی نگذارش (`.gitignore` بسته آن را کنار می‌گذارد).
- فایل JSON کلید گوگل را هم با کسی به اشتراک نگذار.
- اگر فکر می‌کنی توکنی لو رفته: `logout` و برداشتن دسترسی در حساب گوگل، و تغییر رمز آپارات.
